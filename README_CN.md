## 项目简介

**测绘地信**是一款面向测绘、GIS 与自然资源业务的轻量化微信小程序。当前开源版本为 **V1.0.0**，不依赖云开发。标准规范与法律法规目录随小程序发布，收藏和最近浏览记录保存在用户本机。

## 主要功能

- 自然资源技术标准、规范及法律法规查询
- 资料搜索、收藏和最近浏览
- GitHub 原文件页面访问
- 度分秒转换、面积换算、比例尺计算
- 高斯分带、中央经线、EPSG 查询
- 两点距离、方位角、坡度等常用测绘计算
- 微信原生标准地图与卫星影像
- Esri World Imagery 与 OpenStreetMap 辅助查看
- 可选高德官方静态地图服务
- 地图定位、地图选点、坐标复制与位置分享

## 开源配置

公开源码按开源发布要求进行了整理，不包含私人凭据。

需要本地使用的可选配置应与公开源码分离。开发时可将：

```text
miniprogram/config.local.example.js
```

复制为：

```text
miniprogram/config.local.js
```

然后仅在本地填写自己环境所需的配置。`config.local.js` 已加入 `.gitignore`，不应提交到公开仓库。

`project.config.json` 默认使用 `touristappid`。实际开发时，请在微信开发者工具本地环境中使用自己的小程序 AppID。

## 图源说明

- **微信原生地图 / 卫星影像**：基于微信小程序 `<map>` 组件。
- **Esri World Imagery**：用于影像辅助浏览，使用时应遵守 Esri 相关服务条款。
- **OpenStreetMap**：用于道路、地名和位置辅助查看，使用时应遵守 OSM Tile Usage Policy 及署名要求。
- **高德地图**：本地配置后调用官方静态地图 Web 服务。
- **腾讯地图能力**：通过微信原生地图能力及 `wx.openLocation` 使用。

## 导入微信开发者工具

1. 克隆或下载本仓库；
2. 在微信开发者工具中选择“导入项目”；
3. 选择仓库根目录；
4. 如有需要，在本地配置自己的小程序 AppID；
5. 按微信小程序后台要求配置相应合法域名；
6. 发布前建议使用真机测试地图、定位及第三方网络访问功能。
